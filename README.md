# MoneyMate Premium

Тёмное Telegram Mini App для учёта личных финансов в рублях.

## Что есть в этой сборке

### Бесплатный тариф
- До 2 кошельков, 3 целей и 3 месячных лимитов.
- Операции, история, регулярные платежи, календарь и базовая сводка.
- Экспорт резервной копии JSON.

### Premium — 179 Telegram Stars за 30 дней
- Личный финансовый помощник на встроенных правилах (без внешнего AI API).
- Неограниченные кошельки и цели, а также персональные лимиты.
- Умная аналитика расходов по категориям.
- Оценочный прогноз расходов и остатка до конца месяца на основе внесённых операций.
- Умные предупреждения о лимитах и риске перерасхода внутри приложения.
- Темы Emerald, Black Gold и Midnight Purple.

Прогноз является оценкой по уже внесённым операциям, а не гарантией будущего остатка. Уведомления формируются при открытии приложения; это не push-уведомления в фоне.

## Развёртывание на Render

1. Сделай резервную копию текущей базы данных, если в ней есть важные данные.
2. Загрузи файлы этого архива в корень GitHub-репозитория, сохранив структуру `static/`.
3. В Render оставь Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
4. В Render Environment должны быть настроены:
   - `BOT_TOKEN` — существующий токен бота (не публикуй его);
   - `REQUIRED_CHANNEL` = `@MoneyMateDiary`;
   - `PUBLIC_BASE_URL` = публичный URL приложения;
   - `TELEGRAM_WEBHOOK_SECRET` = самостоятельно сгенерированная секретная строка.
5. Бот должен быть администратором `@MoneyMateDiary`.
6. После деплоя проверь `/api/health`, затем открой Mini App через Telegram.

## Важно перед реальной продажей

- Используй PostgreSQL или постоянный диск. SQLite на эфемерной файловой системе бесплатного Render может потерять данные при перезапуске/деплое. Потеря таблицы подписок означает потерю локального статуса Premium.
- В этой версии включена серверная проверка Premium для помощника, аналитики, настроек тем и лимитов количества объектов.
- Webhook проверяет секрет, сумму, валюту и владельца платежа; повторная доставка одного Telegram charge ID не активирует оплату повторно.
- До публичного запуска обязательно проверь полный платёжный цикл в тестовом Telegram-окружении, включая продление подписки и возврат/отмену.
- Встроенный помощник — локальный алгоритмический анализатор, не генеративная нейросеть и не профессиональная финансовая консультация.
