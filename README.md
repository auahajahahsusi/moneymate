# MoneyMate — обновление

Telegram Mini App для личных финансов. Интерфейс на русском, валюта — российский рубль (₽).

## Что добавлено
- Регулярные доходы и расходы: еженедельно, ежемесячно, ежегодно.
- Автоматическое создание пропущенных повторяющихся операций при открытии приложения.
- Пауза, возобновление и удаление регулярных платежей.
- Индикатор финансового здоровья 1–100 с объяснением составляющих оценки.
- Сохранены тёмная тема, овальная навигация, анимации, история, цели и бюджет 50/30/20.

## Важно о напоминаниях
Ближайшая дата следующего платежа отображается в разделе «Платежи». Автоматическое добавление наступивших операций происходит при открытии Mini App. Push-уведомления Telegram в этой версии не отправляются.

## Deploy on Render
- В корне репозитория должны быть `app.py`, `requirements.txt`, `render.yaml` и папка `static/`.
- Build command: `pip install -r requirements.txt`
- Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
- В Render Environment задай `BOT_TOKEN` (токен BotFather). Не публикуй его в GitHub.
- Затем Deploy latest commit.

## Важное замечание о данных
Проект использует SQLite. На бесплатном Render файловая система может быть временной, поэтому данные могут потеряться при перезапуске или деплое. Перед внесением важных финансовых данных подключи постоянное хранилище или PostgreSQL.

## Оценка финансового здоровья
Это ориентировочный показатель по данным текущего месяца, а не кредитный рейтинг и не финансовая рекомендация. Для расчёта используются доля сбережений, положительность баланса, уровень расходов относительно доходов и наличие цели с названием «резерв» или «подушка».
